# DISTORSIÓN — Cultura, Letras y Ruido

Revista digital estática (HTML/CSS/JS). Lista para **GitHub Pages**.

## Ver en local

1. Cloná o descargá el repo
2. Abrí `index.html` en el navegador

## Publicar con GitHub Pages

1. Entrá a **Settings → Pages**
2. En **Source** elegí **Deploy from a branch**
3. Branch: `main` · carpeta: `/ (root)`
4. Guardá. En 1–2 minutos el sitio queda en:

`https://marolynregueiro-source.github.io/distorsion/`
